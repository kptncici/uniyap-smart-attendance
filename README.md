# UNIYAP Smart Attendance

Realtime QR Attendance System for Campus

## Features
- QR Attendance
- Multi Role Authentication
- Realtime Attendance
- Anti Proxy Attendance
- Dashboard Analytics
- Export Excel
- Attendance Reports

## Tech Stack
- Express.js
- Prisma ORM
- Supabase PostgreSQL
- Socket.IO
- EJS
- TailwindCSS

Fullstack Sistem Absensi QR Code (extended)
- Admin CRUD UI (table) with edit/delete
- Dosen: generate QR, download, view attendance
- Mahasiswa: camera scanner (jsQR) + submit
Setup: same as README in zip; use NeonDB for DATABASE_URL.
